# SQL Injection Vulnerability Assessment

## Project Overview

This practical focuses on identifying and understanding SQL injection vulnerabilities in a controlled DVWA laboratory environment.

## Objectives

- Understand how SQL injection vulnerabilities occur.
- Examine weaknesses in SQL query construction.
- Explore secure coding techniques.
- Demonstrate how parameterized queries help prevent SQL injection. 

## Practical Evidence

This practical was conducted in a controlled DVWA laboratory environment using Burp Suite.

The report contains screenshots documenting SQL injection testing and the observed application responses.
