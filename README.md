##  AltSchool Africa Cybersecurity Capstone

My capstone project covered four practical security assessments.

### 1. Access Control Vulnerability Assessment
- Investigated an Insecure Direct Object Reference (IDOR) vulnerability.
- Used PortSwigger Web Security Academy.
- Analyzed unauthorized access to user resources.
- Documented the security impact and remediation recommendations.

### 2. Wi-Fi Security Assessment
- Analyzed a WPA handshake capture using Wireshark.
- Conducted password-strength auditing using Aircrack-ng.
- Examined the risks associated with weak Wi-Fi passwords.
- Recommended stronger passphrases and WPA3.

### 3. SQL Injection Assessment
- Tested SQL injection vulnerabilities in DVWA.
- Used Burp Suite to inspect and modify requests.
- Analyzed weaknesses in input handling.
- Documented security risks and remediation strategies.

### 4. Secure Coding Implementation
- Developed a Python-based database lookup example.
- Used parameterized SQL queries.
- Implemented numeric input validation.
- Added security logging and generic error handling.
