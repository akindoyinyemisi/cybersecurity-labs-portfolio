# Secure Coding Task and Implementation

## Project Overview

This project documents a secure coding practical using Python and MySQL.

The task focuses on identifying and preventing common security vulnerabilities in database-driven applications.

## Objectives

- Implement secure database interactions.
- Prevent SQL injection using parameterized queries.
- Validate user input.
- Implement security logging.
- Improve application security through secure coding practices.

## Technologies Used

- Python
- MySQL
- MySQL Connector
- Regular Expressions (re)
- Python Logging Module

## Security Features

### 1. SQL Injection Prevention
Uses parameterized queries to reduce the risk of SQL injection attacks.

### 2. Input Validation
Uses input validation to check user-supplied data.

### 3. Security Logging
Records suspicious input and security-related events.
